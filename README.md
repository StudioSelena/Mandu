# Mandudu!

삶아지는 만두를 딱 알맞은 순간에 건져 내는 1버튼 타이밍 게임입니다.
흘러가는 시간은 보여 주지 않습니다. 오로지 감으로 맞혀야 합니다.

## 다운로드

[Releases](https://github.com/StudioSelena/Mandu/releases)에서 최신 버전 압축 파일을 받아 풀고 `Mandudu.exe`를 실행하세요.
Windows에서 실행됩니다.

## 플레이 방법

1. 스테이지에 들어가면 목표 시간이 나옵니다.
2. 삶기 버튼을 누르면 만두가 삶아지기 시작합니다.
3. 목표 시간이 됐다고 느끼는 순간 **스페이스 바**를 눌러 만두를 건집니다.
4. 목표 시간과 얼마나 차이 나는지에 따라 등급이 나옵니다.

| 등급 | 조건 |
|---|---|
| MONSTER | 오차 0ms |
| PERFECT, NICE, GOOD | 오차가 작을수록 높은 등급 |
| FAIL | 허용 범위를 넘김 |

GOOD 이상을 받으면 다음 스테이지가 열립니다.
5스테이지부터는 방해요소가 끼어듭니다.
